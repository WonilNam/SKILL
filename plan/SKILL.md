# Plan

目标：在动手前明确真实影响、设计取舍、行为变化、验证路径和决策门禁，然后继续执行。

## Depth

- **Focused**：少量相关文件，简述方案后执行。
- **High**：跨层、公共契约、数据库或状态机，列出影响与验证后执行。
- **Full**：迁移、删除、发布或跨系统集成，先建立仓库地图、回滚边界和决策门禁。

## Required Content

- 目标行为与当前证据。
- 可能新增、修改、删除的真实文件或模块。
- 方案解决的问题、取舍和用户可观察变化。
- 测试、构建、类型检查、手工验证及无法验证项。
- 仅列真实门禁；需求清晰且风险可控时计划后直接实现。

## Decision Gates

破坏性数据迁移、公共契约破坏、未知业务/协议语义、生产操作、发布或 Git 历史改写需要用户决定。普通实现、测试补齐和代码文档同步不需要重复确认。

计划必须来自已读文件；证据变化时更新计划。不要填空标题、虚构路径或为小改动制造流程。
